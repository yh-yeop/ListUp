## 이메일 대신 아이디로 가입

계정을 **아이디와 비밀번호**로 만듭니다. 그동안 가입 칸이 "이메일"이었지만 ListUp 은 메일을 보낸 적이 없고(비밀번호
재설정은 서버 주인이 주는 코드로 합니다) 계정도 서버마다 따로라, 친구 서버에 진짜 메일 주소를 줄 필요가 없었습니다.
그리고 설치한 앱의 **버전을 서버 목록에서 바로** 보고, 업데이트를 직접 확인할 수 있습니다.

### 받을 것

| 파일 | 누구에게 |
| --- | --- |
| `listup-1.6.0-windows-setup.exe` | PC 앱. 이전 버전 위에 덮어 설치됩니다 — 서버 목록·설정·서버 데이터는 그대로 |
| `listup-1.6.0-android.apk` | 안드로이드 앱. **1.5.0 위에 덮어 설치됩니다** |
| `listup-1.6.0.zip` | 명령줄로 서버를 여는 사람. 압축을 풀고 `npm install` → `npm run serve -- --tunnel` |

안드로이드에 아직 **1.3.0** 이 깔려 있다면 1.5.0 때처럼 한 번 지우고 설치해야 합니다(앱 서명 키가 바뀌었습니다 —
[1.5.0 안내](https://github.com/yh-yeop/ListUp/releases/tag/v1.5.0)). 1.5.0 부터는 계속 덮어 설치됩니다.

PC 앱은 코드 서명을 하지 않아 Windows 가 "PC 보호" 경고를 띄웁니다 — **추가 정보 → 실행**.

### 새로 된 것

- **아이디로 가입** — 3~64자, 글자나 숫자로 시작하고 글자·숫자와 `. _ - @ +` 를 쓸 수 있습니다(한글도 됩니다).
  대소문자는 가리지 않습니다 — `Hong` 과 `hong` 은 같은 아이디입니다.
  - **이메일로 가입했던 계정은 그대로입니다.** 그 이메일이 곧 아이디라, 지금처럼 넣고 로그인하면 됩니다.
  - 이메일 모양 아이디로 새로 가입하는 것도 계속 됩니다.
  - 내 정보·멤버 목록(소유자에게만)에 아이디가 보입니다. 비밀번호를 잊으면 서버 주인에게 **아이디**를 알려 주고
    재설정 코드를 받습니다(PC 앱: 관리 → 비밀번호를 잊은 사람, 명령줄: `npm run reset-password -- <아이디>`).
- **서버 목록에서 버전 보기** — 서버 목록과 내 정보 아래에 `ListUp PC 앱 v1.6.0` 처럼 앱 종류와 버전이 보입니다.
  로그인하지 않아도 보입니다.
- **업데이트 확인** — 그 아래 **업데이트 확인**을 누르면 바로 GitHub 에 묻습니다. 최신이면 최신이라고, 닿지 못하면
  확인하지 못했다고 알려 줍니다. 새 버전이 있으면 이 기기에 맞는 파일(APK·PC 설치 파일)을 짚어 줍니다.

### 호환

- **서버도 1.6.0 으로 올려 주세요.** 1.5.0 이하 서버는 아직 이메일 모양만 받아서, 1.6.0 앱으로 그런 서버에 `hong`
  같은 아이디로 가입하면 "이메일 형식이 올바르지 않습니다"가 뜹니다. 이메일 모양으로는 가입되고, 로그인은 그대로 됩니다.
- 1.5.0 이하 앱도 1.6.0 서버에 그대로 붙습니다(로그인 칸 이름만 "이메일"로 보입니다 — 아이디를 넣으면 됩니다).
- DB 구조는 바뀌지 않았습니다.
