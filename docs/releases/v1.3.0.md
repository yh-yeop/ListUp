## PC 앱 — 설치해서 쓰고, 이 PC 에서 서버도 열고

Windows 용 **PC 앱**이 생겼습니다. 서버 목록에서 들어갈 서버를 고르는 클라이언트이면서, **Node 설치나 터미널
없이 이 PC 를 ListUp 서버로 여는 곳**이기도 합니다. 그리고 기기의 폴더와 저장소를 견주는 **내 폴더와 비교**가 들어갔습니다.

### 받을 것

| 파일 | 누구에게 |
| --- | --- |
| `listup-1.3.0-windows-setup.exe` | **PC 앱 (새로 나옴).** 서버에 들어가거나, 이 PC 에서 서버를 엽니다 |
| `listup-1.3.0-android.apk` | 안드로이드 앱. 1.2.x 위에 덮어 설치됩니다 |
| `listup-1.3.0.zip` | 명령줄로 서버를 여는 사람. 압축을 풀고 `npm install` → `npm run serve -- --tunnel` |

PC 앱은 코드 서명을 하지 않아 Windows 가 "PC 보호" 경고를 띄웁니다 — **추가 정보 → 실행**.

### 새로 된 것

- **PC 앱에서 서버 열기** — 서버 목록 맨 위 **이 PC 에서 서버 열기 → 서버 켜기**. **관리** 화면에서
  - 밖에서 들어오기: 공개하지 않음 / Tailscale Funnel(고정 주소) / Cloudflare 빠른 터널
  - 비밀번호를 잊은 사람에게 재설정 코드 발급
  - 앱을 열 때 서버도 켜기, Windows 에 로그인하면 창 없이 켜기, 포트
  - 데이터 폴더 열기·바꾸기, 백업(DB 사본 + 파일), 최근 로그

  창을 닫아도 서버가 켜져 있으면 트레이에 남아 계속 돕니다. "이 PC" 로 들어가 만든 초대 링크에는 localhost 대신
  공개 주소(없으면 공유기 안 주소)가 들어갑니다. 명령줄 서버로 쓰던 데이터(`server/data`)는 서버를 끈 채
  **다른 폴더 쓰기**로 고르면 계정·로그인이 그대로 이어집니다.
- **내 폴더와 비교** — 저장소 화면의 **내 폴더와 비교**. 기기의 폴더를 그때그때 골라 파일 이름으로 견줍니다
  (하위 폴더 경로까지 / 이름만). "저장소에만" 있는 것은 골라 받고, "내 폴더에만" 있는 것은 골라 올립니다
  (열람 권한이면 변경 제안으로). 크기가 다르면 표시합니다.
  - PC 앱·안드로이드: 받은 파일을 고른 폴더 안에 폴더 구조대로 바로 넣습니다.
  - 브라우저: 폴더에 쓸 수 없어 받기는 브라우저의 내려받기 폴더로 갑니다.
- PC 앱도 **로그인 정보 저장**을 씁니다(Windows 가 암호화).

### 고친 것

- **터널 뒤에서 한 사람이 로그인을 10번 틀리면 접속자 전원이 15분 막히던 문제.** 터널은 같은 PC 에서 붙어 모든
  접속자가 같은 주소로 보였습니다. 이제 이 PC 에서 붙은 프록시(터널)가 알려 주는 실제 접속 주소로 셉니다
  (`LISTUP_TRUST_PROXY` 기본값 `loopback`).

### 호환

- 1.3.0 앱은 1.2.x 서버에 그대로 들어갑니다(내 폴더와 비교도 됩니다 — 조금 느릴 뿐).
- 1.2.x 앱도 1.3.0 서버에 그대로 붙습니다. DB 구조는 바뀌지 않았습니다.

### 명령줄 서버를 1.2.x 에서 올리는 사람

- **Node 22 이상이 필요합니다** (SQLite 모듈을 올렸습니다 — 대신 설치할 때 빌드 도구가 필요 없습니다).
- 프록시를 모두 믿게 `LISTUP_TRUST_PROXY=1` 로 켜 두었다면 그대로 두어도 되고, 터널만 쓴다면 지워도 됩니다.
