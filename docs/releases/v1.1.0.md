## 설치형 클라이언트 — 서버가 꺼져 있어도 켜지는 앱

마인크래프트처럼 **클라이언트는 설치해 두고, 서버 목록은 앱이 들고, 들어갈 때만 서버에 붙는** 구조가
됐습니다. 계정은 서버마다 따로입니다.

### 받을 것

| 파일 | 누구에게 |
| --- | --- |
| `listup-1.1.0-android.apk` | 안드로이드 폰에 설치하는 앱. 서버 없이도 켜집니다 |
| `listup-1.1.0.zip` | 서버를 여는 사람. 압축을 풀고 `npm install` → `npm run serve -- --tunnel` |

APK 는 "출처를 알 수 없는 앱" 설치를 허용해야 설치됩니다.

### 새로 된 것

- **서버 목록** — 여러 서버를 기억하고 골라 들어갑니다. 한 번 로그인한 서버는 다시 고를 때 로그인하지
  않아도 됩니다. 목록을 열면 서버마다 "연결됨 / 닿지 않음 / 서버가 오래됨 / 앱 업데이트 필요" 를 보여 줍니다.
- **안드로이드 앱** — 설치해 두면 서버와 PC 가 꺼져 있어도 켜집니다. 같은 공유기의 `http://` 서버와 터널의
  `https://` 서버에 모두 붙습니다.
- **로그인 정보 저장** — 앱이 서버마다 이메일·비밀번호를 기기에 암호화해 두고, 로그인이 풀리면 다시
  로그인합니다. 직접 로그아웃한 서버는 자동으로 들어가지 않습니다.
- **버전 확인** — 서버와 앱의 API 버전이 다르면 들어가지 않고 이유를 알려 줍니다. 서버의
  `/api/health` 가 `apiVersion` 과 `version` 을 알려 줍니다. 1.0.0 서버에도 그대로 붙습니다.
- **업데이트 알림** — 앱이 새 릴리즈를 찾으면 한 번 알려 주고, 앱이 서버보다 오래돼 들어갈 수 없으면
  릴리즈 페이지를 바로 엽니다.

### 서버를 1.0.0 에서 올리는 사람

데이터(`server/data`)는 그대로 씁니다. 스키마 변경은 없습니다.
