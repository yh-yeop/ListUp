## 사람 사이에 쓰기 편하게 — 초대·참여·협업 보강

초대받은 사람이 **덜 헤매고 바로 참여**하도록, 그리고 여럿이 쓸 때 **내 제안이 어떻게 됐는지, 누가 드나들었는지**
한눈에 보이도록 다듬었습니다. 로그아웃·계정 보안도 손봤습니다.

> **서버도 1.8.0 으로 올려 주세요.** 아래 「호환」에 올려야 하는 이유(로그아웃 보안, 새 기능 몇 가지)가 있습니다.
> 서버를 올릴 때 **서명 키 형식 검사**(맨 앞 항목)를 먼저 읽어 주세요 — 드물지만 서버가 켜지지 않을 수 있습니다.

### 받을 것

| 파일 | 누구에게 |
| --- | --- |
| `listup-1.8.0-windows-setup.exe` | PC 앱. 이전 버전 위에 덮어 설치됩니다 — 서버 목록·설정·서버 데이터는 그대로 |
| `listup-1.8.0-android.apk` | 안드로이드 앱. **1.5.0 이상 위에 덮어 설치됩니다** (1.3.0 이면 [1.5.0 안내](https://github.com/yh-yeop/ListUp/releases/tag/v1.5.0)대로 한 번 지우고 설치) |
| `listup-1.8.0.zip` | 명령줄로 서버를 여는 사람. 압축을 풀고 `npm install` → `npm run serve -- --tunnel` |
| `latest.yml`, `….blockmap` | PC 앱 자동 업데이트가 읽는 파일입니다. 받을 필요 없습니다 |

1.7.0 이상 앱은 이 버전을 **알아서 받아 설치**합니다(PC 앱은 다시 시작할 때, 안드로이드는 알림에서 받아서 설치).
PC 앱은 코드 서명을 하지 않아 Windows 가 "PC 보호" 경고를 띄웁니다 — **추가 정보 → 실행**.

### 새로 된 것

- **초대·참여가 쉬워졌습니다.**
  - **서버 주소를 일부만 적어도 됩니다.** `192.168.0.10` 이나 `<내 노드>.<tailnet>.ts.net` 처럼 적으면 `http(s)://`·
    포트(4000)를 붙인 후보를 차례로 확인해 닿는 주소로 저장합니다. '연결 확인'과 '저장하고 들어가기'를 따로 누르지
    않아도 한 번에 됩니다.
  - **초대 QR 코드.** 초대 화면에서 **QR 코드**를 펼쳐 옆 사람이 폰 카메라로 찍으면 참여 링크가 바로 열립니다.
    복사하는 공유 문구에는 저장소 이름·권한·기한과 앱 없이 여는 법이 함께 들어갑니다.
  - **가입 전에 어떤 저장소인지 먼저 보고, 가입하면 바로 참여.** 초대 링크를 열면 로그인·가입 전에도 저장소 이름·
    소유자·권한이 보입니다. 미리 보고 가입·로그인하면 '참여'를 한 번 더 누르지 않고 바로 들어갑니다.
  - **PC 앱 처음 시작하기.** 서버를 처음 여는 사람에게 서버 켜기 → 밖에서 들어오게 → 서버 이름 → 내 계정 만들기를
    체크리스트로 안내합니다. **비밀번호 보기** 버튼도 로그인·가입·재설정·설정 칸에 생겼습니다.
- **여럿이 쓸 때 보이는 것.**
  - **내 제안.** 저장소 목록 위 **내 제안**에서 저장소를 가로질러 내가 올린 제안을 봅니다. 반영·닫힘이나 남이 단 의견이
    있으면 **새 소식**으로 표시되고, 제안을 닫은 사람이 적은 **이유**도 의견으로 남습니다.
  - **활동 기록.** 소유자는 멤버 화면의 **활동 기록**에서 참여·나감·내보내기·권한 변경·소유권 이전·초대 발급·회수를 봅니다.
  - **다른 기기 모두 로그아웃.** 내 정보에서 이 기기만 남기고 다른 기기의 로그인을 모두 끊습니다. 기기를 잃어버렸다면
    비밀번호도 함께 바꾸세요(저장해 둔 기기가 다시 들어올 수 있습니다).
- **목록 다루기.**
  - 제안이 많으면 **30개씩 받고 '더 보기'** 로 이어 받습니다. 저장소가 5개 이상이면 목록 위에 **저장소 찾기** 칸이 생깁니다.
  - 파일·폴더 행에는 받기와 **⋯** 만 두고, ⋯ 를 누르면 버전·이름 변경·삭제가 글자 버튼으로 펼쳐집니다(좁은 폰에서
    이름이 가리지 않게).
- **서버를 여는 사람을 위한 진단.** PC 앱 서버 로그가 `logs/server.log` 에도 남아(로그 폴더 열기) 앱을 다시 켜도
  볼 수 있고, 서버 오류 문장 끝에 **오류 번호**가 붙습니다. 들어온 사람이 그 번호를 알려 주면 로그에서 같은 줄을 찾습니다.

### 호환

- **「중요」 서명 키 형식을 이제 검사합니다 — 드물게 서버가 켜지지 않을 수 있습니다.**
  - `npm run serve`·PC 앱: 데이터 폴더의 `auth-secret.txt` 가 **64자 16진수**가 아니면 새 키를 만들지 않고 켜지지
    않습니다(새 키는 모두 로그아웃되는 것과 같아서). 지금까지 `npm run serve`·PC 앱·예전 `deploy-tunnel.ps1` 이 만든
    파일은 이미 이 형식이라 그대로 켜집니다 — 손으로 다른 값을 넣은 경우에만 걸립니다. 그럴 때는 백업에서 되살리거나,
    모두 다시 로그인해도 되면 그 파일을 지우고 다시 켜세요.
  - `LISTUP_AUTH_SECRET` 을 직접 주는 경우: **32자 이상**이어야 하고 빈 값(`LISTUP_AUTH_SECRET=`)은 개발 모드에서도
    거부합니다. 짧으면 `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` 로 새로 만드세요(바꾸면
    모두 다시 로그인합니다).
- **「보안」 로그아웃이 서버에서도 토큰을 끊습니다.** 예전에는 토큰을 서버에 저장하지 않아, 로그아웃은 앱이 기기에서
  토큰을 지우는 것뿐이었고 복사해 둔 토큰은 만료(기본 30일)까지 통했습니다. 이제 로그아웃하면 그 토큰을 서버가
  만료 때까지 거부하고, **다른 기기 모두 로그아웃**과 비밀번호 변경은 그 사용자의 토큰을 한꺼번에 끊습니다.
  - **서버를 1.8.0 으로 올려야 적용됩니다.** 1.8 앱이 옛(1.7 이하) 서버에 붙으면 로그아웃은 기기에서만 지웁니다.
- **「새 기능 — 서버 필요」** 내 제안·활동 기록·다른 기기 모두 로그아웃·로그인 없는 초대 미리보기는 서버가 1.8.0 이어야
  동작합니다(`apiLevel` 5). 1.8 앱이 옛 서버에 붙으면 이 버튼·화면은 "서버를 1.8 이상으로"만 안내합니다. 제안 목록
  나눠 받기(`apiLevel` 4)는 옛 서버에서 한 번에 전부 주므로 그대로 쓰입니다.
- **「바뀐 것」** 서버 오류의 `requestId` 값 모양이 바뀌었습니다(무작위 10자 16진수, 재시작해도 겹치지 않음). API 호환
  버전(`apiVersion`)은 1 그대로라, 1.7 이하 앱도 1.8 서버에 그대로 붙고 그 반대도 됩니다.
- **「없어진 것」** 배포 묶음에 없던 `deploy-tunnel.ps1` 을 리포에서 지웠습니다. 같은 일은 `npm run serve -- --tunnel`
  (빠른 터널만 쓰려면 `npm run tunnel use quick`)이나 PC 앱 **밖에서 들어오기**로 합니다.
- **DB 구조:** 마이그레이션 9 가 자동으로 적용됩니다(로그아웃 토큰·제안 결정 정보·활동 기록용 표). 올리기 전에 있었던
  일은 활동 기록에 없고, 그 전에 결정된 제안은 결정한 사람을 모릅니다.
