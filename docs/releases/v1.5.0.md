## 되돌리기·휴지통·검색, 그리고 흐름을 끊지 않는 앱

지운 파일과 예전 버전을 **다시 올리지 않고 되돌리는** 휴지통·파일 버전, 저장소 전체 **파일 검색**이 들어갔습니다.
올리는 도중 **멈추기**와, 멈췄다가 다시 올릴 때 **이미 올린 파일 건너뛰기**도 생겼습니다. 안내는 이제 흐름을 끊는
팝업 대신 화면 아래 토스트로 뜹니다. (1.4.0 은 따로 내지 않고 이번에 함께 담았습니다.)

> **안드로이드는 이번 한 번, 앱을 지우고 새로 설치해야 합니다.**
> 앱 서명 키가 바뀌어 1.3.0 위에 덮어 설치되지 않습니다("앱이 설치되지 않았습니다"가 뜹니다).
> 1. 설치된 ListUp 의 서버 주소를 적어 둡니다(서버 목록의 각 서버 → 설정). 초대 링크가 있으면 그것으로도 됩니다.
> 2. ListUp 을 지우고 `listup-1.5.0-android.apk` 를 설치합니다.
> 3. 서버를 다시 더하고 로그인합니다.
>
> **계정·저장소·파일은 서버에 있어 그대로입니다.** 사라지는 것은 폰에 저장된 서버 목록과 저장된 로그인뿐입니다.
> 다음 버전부터는 다시 덮어 설치됩니다.

### 받을 것

| 파일 | 누구에게 |
| --- | --- |
| `listup-1.5.0-windows-setup.exe` | PC 앱. 1.3.0 위에 덮어 설치됩니다 — 서버 목록·설정·서버 데이터는 그대로 |
| `listup-1.5.0-android.apk` | 안드로이드 앱. **이번만 1.3.0 을 지우고 설치** (위 안내) |
| `listup-1.5.0.zip` | 명령줄로 서버를 여는 사람. 압축을 풀고 `npm install` → `npm run serve -- --tunnel` |

PC 앱은 코드 서명을 하지 않아 Windows 가 "PC 보호" 경고를 띄웁니다 — **추가 정보 → 실행**.

### 새로 된 것

- **휴지통** — 변경 이력 → **휴지통**. 지워서 지금 없는 파일이 지운 때마다 묶여 나옵니다(폴더를 지웠다면 그 안의
  파일이 한 묶음). 하나씩, 또는 묶음째 원래 자리로 되돌립니다. 이름을 바꾸거나 옮긴 파일은 나오지 않습니다.
- **파일 버전** — 파일 줄의 시계 아이콘. 그 파일이 바뀐 시점들(추가·수정·삭제)을 보고, 예전 버전을 받거나
  **이 버전으로 되돌리기**. 되돌려도 지금 내용은 이력에 남아 다시 되돌릴 수 있습니다.
  - 되돌리기는 파일을 다시 올리지 않아 큰 파일도 바로 됩니다.
  - 열람 권한이면 같은 내용으로 **변경 제안**을 만들고, 편집자가 확인한 뒤 반영합니다.
- **파일 찾기** — 저장소 화면의 **저장소 전체에서 파일 찾기**. 띄어 쓴 낱말이 모두 들어간 파일을 찾고, 파일
  이름에서 찾은 것을 먼저 보여 줍니다. 결과에서 바로 받기·버전·그 폴더 열기. 과거 시점을 보는 중에도 됩니다.
- **멈추기** — 올리기·받기 진행률의 **멈추기**. 그때까지 다 올린 파일은 반영하고 나머지는 올리지 않습니다.
- **이미 올린 파일 건너뛰기** — 파일·폴더를 올릴 때 같은 경로에 같은 크기로 이미 있고, 기기의 파일을 올린 뒤로
  고치지 않았으면 건너뜁니다. 큰 폴더를 멈췄다가 다시 올리면 남은 것만 갑니다. 크기가 같아도 고친 파일(태그만
  고친 음악 등)은 올립니다.
- **안내가 토스트로** — "올렸습니다", "복사했습니다" 같은 안내가 화면 아래에 잠깐 떴다 사라집니다. 누르면 닫히고,
  실패는 붉게 더 오래 남습니다. 지울지처럼 골라야 하는 것만 그대로 묻습니다.
- **서버 이름** — 서버 주인이 이름을 정해 두면, 초대받은 사람이 서버를 더할 때 그 이름이 목록에 들어갑니다.
  - PC 앱: 이 PC 서버 **관리 → 실행 → 서버 이름** (서버를 다시 켜면 적용)
  - 명령줄 서버: `LISTUP_SERVER_NAME=우리집 음악서버`

### 바뀐 말

- 제안을 저장소에 넣는 것을 모두 **반영**이라고 부릅니다(이전의 "병합"). 제안 상태 "병합됨" → **반영됨**.
- 제안을 시작하는 버튼은 모두 **변경 제안 만들기**, 가입 화면 제목은 **회원가입**.
- 만료 시각은 `오늘 15:20` · `내일 09:00` · `2026.10.27 15:20` 처럼 한 가지로 씁니다.

### 호환

- 1.5.0 앱은 1.3.0 서버에도 들어갑니다. 휴지통·파일 버전 화면만 "서버를 1.5 이상으로 업데이트해 달라"고 안내하고,
  나머지는 그대로 됩니다.
- 1.3.0 앱도 1.5.0 서버에 그대로 붙습니다.
- 서버는 처음 켤 때 DB 에 색인 하나를 더합니다(금방 끝납니다). 1.3.0 서버로 다시 내려가도 그대로 열립니다.
