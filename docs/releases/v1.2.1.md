## 안드로이드에서 "내려받기"가 진짜로 저장되게

1.2.0 의 안드로이드 앱은 내려받기를 누르면 파일을 받은 뒤 **공유 창**을 띄워, 휴대폰에 저장되지 않았습니다.

### 바뀐 것

- **처음 내려받을 때 한 번 저장 폴더를 고르면**, 그다음부터는 누르는 즉시 그 폴더에 저장합니다.
  - 안드로이드는 "Download" 폴더 자체를 고르지 못하게 막아 두었습니다. 폴더 선택기에서 Download 안에
    **새 폴더(예: ListUp)** 를 만들어 고르세요.
  - 같은 이름의 파일이 있으면 덮어쓰지 않고 `이름 (1).확장자` 로 저장합니다.
  - 폴더 zip 받기와 변경 제안의 파일 받기도 같습니다.
- 설정(내 정보)의 **받은 파일 저장 폴더** 에서 폴더를 바꿀 수 있습니다.

### 받을 것

| 파일 | 누구에게 |
| --- | --- |
| `listup-1.2.1-android.apk` | 안드로이드 앱. 1.2.0 위에 덮어 설치됩니다 |
| `listup-1.2.1.zip` | 서버를 여는 사람. **서버는 1.2.0 과 같습니다** — 1.2.0 서버를 그대로 써도 됩니다 |
