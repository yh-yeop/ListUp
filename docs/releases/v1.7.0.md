## 업데이트를 앱 안에서

새 버전이 나오면 더 이상 릴리즈 페이지에서 파일을 골라 받지 않아도 됩니다. **PC 앱은 스스로 새 버전을 받아 두었다가
다시 시작할 때 설치**하고, **안드로이드 앱은 새 버전을 받아 바로 설치 화면을 띄웁니다.**

> **이번 한 번은 직접 설치해 주세요.** 앱 안 업데이트는 1.7.0 에 들어 있어서, 지금 쓰는 1.6.0 이하 앱은 아래 파일을
> 받아 설치해야 합니다. 1.7.0 부터는 다음 버전을 앱이 알아서 받습니다.

### 받을 것

| 파일 | 누구에게 |
| --- | --- |
| `listup-1.7.0-windows-setup.exe` | PC 앱. 이전 버전 위에 덮어 설치됩니다 — 서버 목록·설정·서버 데이터는 그대로 |
| `listup-1.7.0-android.apk` | 안드로이드 앱. 1.5.0 이상 위에 덮어 설치됩니다 (1.3.0 이면 [1.5.0 안내](https://github.com/yh-yeop/ListUp/releases/tag/v1.5.0)대로 한 번 지우고 설치) |
| `listup-1.7.0.zip` | 명령줄로 서버를 여는 사람. 압축을 풀고 `npm install` → `npm run serve -- --tunnel` |
| `latest.yml`, `….blockmap` | PC 앱 자동 업데이트가 읽는 파일입니다. 받을 필요 없습니다 |

PC 앱은 코드 서명을 하지 않아 Windows 가 "PC 보호" 경고를 띄웁니다 — **추가 정보 → 실행**.

### 새로 된 것

- **PC 앱 자동 업데이트** — 앱이 켜져 있으면 새 버전을 확인해(켜고 조금 뒤, 그 뒤로 6시간마다) 백그라운드로 받아
  둡니다. 다 받으면 **다시 시작해 설치**할지 한 번 묻고, 미뤄도 ListUp 을 끝낼 때 설치됩니다.
  - **켜 둔 서버는 설치 뒤 다시 켜집니다.** 설치하는 동안 잠깐 꺼집니다.
  - 서버 목록·내 정보 아래, 트레이 메뉴에서도 받는 중인지, 설치할 준비가 됐는지 보입니다. **업데이트 확인**으로 바로
    확인할 수도 있습니다.
  - 받은 파일은 릴리즈에 적힌 해시(sha512)와 맞는지 확인한 뒤에만 설치합니다.
- **안드로이드 앱 안 업데이트** — 새 버전 알림에서 **받아서 설치**를 누르면 앱이 새 APK 를 받고 설치 화면을 띄웁니다.
  서버 목록·내 정보의 **새 버전 받아 설치**도 같습니다.
  - 처음 한 번은 안드로이드가 "이 출처의 앱 설치 허용"을 묻습니다 — 허용하고 돌아오면 됩니다.
  - 설치 화면이 앱 서명을 확인하므로, ListUp 과 같은 키로 서명된 APK 만 덮어 설치됩니다.

### 호환

- 서버는 바뀌지 않았습니다(1.6.0 과 같음). 1.7.0 앱은 1.6.0 서버에 그대로 들어가고, 그 반대도 그대로입니다.
