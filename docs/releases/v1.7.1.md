## 작은 다듬기

1.7.0 의 PC 앱 자동 업데이트·안드로이드 앱 안 업데이트로 받는 첫 버전입니다. **1.7.0 을 쓰고 있다면 따로 받을 필요가
없습니다** — PC 앱은 알아서 받아 두고 다시 시작할 때 설치하고, 안드로이드 앱은 새 버전 알림에서 **받아서 설치**를 누르면 됩니다.

### 받을 것

| 파일 | 누구에게 |
| --- | --- |
| `listup-1.7.1-windows-setup.exe` | PC 앱. 1.6.0 이하에서 올 때만 직접 설치 — 1.7.0 은 자동으로 |
| `listup-1.7.1-android.apk` | 안드로이드 앱. 1.6.0 이하에서 올 때만 직접 설치 — 1.7.0 은 앱 안에서 |
| `listup-1.7.1.zip` | 명령줄로 서버를 여는 사람 |
| `latest.yml`, `….blockmap` | PC 앱 자동 업데이트가 읽는 파일입니다. 받을 필요 없습니다 |

### 바뀐 것

- **트레이에 있어도 업데이트를 알려 줍니다** — 서버를 켜 두고 창을 닫아 트레이에 둔 PC 앱도, 새 버전을 다 받으면
  Windows 알림을 한 번 띄웁니다. 누르면 창이 열려 **다시 시작해 설치**할 수 있습니다.
- **라이트 테마의 파란 글자가 더 잘 보입니다** — 활성 탭·필터 칩·링크의 파란색을 조금 진하게 해 연한 배경 위에서도
  읽기 쉬운 대비(WCAG AA)를 맞췄습니다.

### 호환

- 서버는 바뀌지 않았습니다(1.6.0·1.7.0 과 같음).
