# UX 개선 계획 — 처음 쓰는 사람·익숙한 사람·문제가 생긴 사람 (2026-11-21)

목표(사용자): "익숙치 않은 사용자도 쉽게 쓸 수 있으며, 기존 사용자도 더 전문적으로 사용 가능하게 하고, 비번찾기 같은
문제해결을 위한 동작들을 추가". 세 갈래로 나눈다 — **(A) 처음 쓰는 사람**, **(B) 익숙한 사람**, **(C) 스스로 문제 풀기**.

진행은 TODO.md 「UX 개선 — 세 갈래」 절이 기준이다. 이 문서는 왜·무엇을 정리해 둔 설계다.

## 1. 지금 모습 — 찾은 문제

### C. 문제가 생겼을 때

- **비밀번호를 잊으면 서버 운영자 말고는 길이 없다.** 재설정 코드는 운영자가 `npm run reset-password` 나 PC 앱
  「이 PC 에서 서버 열기」에서만 발급한다(`server/src/services/password-reset.ts`, `app/app/host.tsx:352`). 운영자가 자고
  있거나 연락이 안 되면 그동안 못 들어간다. 이메일이 없는 시스템이라(1.6.0 에 아이디로 바꿈) "메일로 재설정"은 없다.
- **아이디를 잊으면 길이 전혀 없다.** 로그인 화면에 아이디 찾기가 없고(`app/app/login.tsx:137` 은 비밀번호뿐), 재설정
  화면도 아이디를 먼저 요구한다(`app/app/reset-password.tsx`). 사실 같은 저장소 멤버 목록에는 아이디가 보이는데
  (`app/app/repo/[repoId]/members.tsx:266`) 그걸 알려 주는 곳이 없다.
- **연결이 안 되면 "닿지 않음" 한 가지뿐이다.** `checkServer` 는 꺼짐·주소 틀림·ListUp 이 아닌 곳·시간 초과·터널 끝남을
  모두 `unreachable` 하나로 접는다(`app/src/state/servers.ts:90,102`). 오류 문장은 "서버가 켜져 있는지 확인"뿐이고
  (`app/src/api/client.ts:259`), 무엇을 차례로 확인할지 알려 주는 화면이 없다.
- **로그인이 끊기면 말없이 로그인 화면으로 간다.** 401 이면 세션만 지운다(`app/src/state/auth.tsx:243`). 비밀번호가 바뀌었거나
  "다른 기기 모두 로그아웃"을 누른 결과인지 사용자는 모른다.
- 로그인 실패(401)·막힘(429) 뒤에 다음에 할 일(재설정·기다리기)을 가리키지 않는다.

### A. 처음 쓰는 사람

- **서버·계정·저장소·역할·제안이라는 말이 처음 보는 사람에게 설명되지 않는다.** 화면마다 한 줄씩 흩어져 있고
  (서버 목록 부제, 저장소 화면의 열람자 안내), 한곳에서 읽을 도움말이 없다.
- **빈 화면이 다음 할 일을 누를 수 있게 주지 않는다.** 저장소가 없을 때 "새 저장소를 만들거나 초대 코드로 참여"라고
  말만 하고 버튼은 위에 따로 있다(`app/app/repos.tsx:194`). 파일이 없을 때도 "파일을 올리면 여기에 표시"뿐이다
  (`app/app/repo/[repoId]/index.tsx:553`).

### B. 익숙한 사람

- **파일 목록을 정렬할 수 없다.** 서버가 준 이름순 그대로다. 큰 파일·최근 바뀐 파일을 찾으려면 훑어야 한다.
- **키보드로 할 수 있는 것이 없다**(웹·PC 앱). 검색 칸으로 가기, 위 폴더로 가기 모두 마우스로만.
- **경로·폴더 주소를 건넬 방법이 없다.** 보고 있는 폴더는 화면 상태라 주소창에 남지 않고(`index.tsx` 의 `path` 상태), 경로를
  복사하는 버튼도 없다. 사람에게 "이 폴더 보세요"를 말로 설명해야 한다.
- **여러 파일을 한꺼번에 지우거나 옮길 수 없다.** 한 줄씩 ⋯ → 삭제. 서버의 여러 파일 커밋(`/files/commit`)은 이미 있다.

## 2. 바꿀 것

### C. 스스로 문제 풀기 (서버 + 앱)

1. **복구 코드 (서버, API_LEVEL 7)** — 운영자 없이 스스로 비밀번호를 되찾는 길.
   - 「내 정보」에서 현재 비밀번호를 다시 넣고 만든다. 한 번에 10개, 각각 한 번만 쓴다. 다시 만들면 이전 것은 모두 무효.
   - 모양 `XXXX-XXXX-XXXX-XXXX`(초대 코드 알파벳 31자 × 16자 ≈ 79비트). 만료가 없으니 초대·재설정 코드(10자·30분)보다 길게.
   - DB 에는 SHA-256 만(`recovery_codes`, 마이그레이션 v10). 원문은 만들 때 한 번만 응답에 실린다.
   - `/auth/reset` 이 운영자 코드와 복구 코드를 **둘 다** 받는다 — 앱에 화면을 하나 더 만들지 않고, 사용자는 "받은 코드"만
     넣으면 된다. 복구 코드는 한 사람 것이라 **아이디 없이도** 그 사람을 찾는다(→ 아이디 찾기).
   - 아이디를 함께 보냈는데 다른 사람의 복구 코드면 실패(남의 코드로 내 계정을 못 연다 — 양쪽 다 400).
   - 성공하면 운영자 코드와 같이 비밀번호를 바꾸고 **토큰 세대를 올린다**(다른 기기 끊김). 실패는 로그인과 같은 제한(IP·아이디)으로 센다.
   - 응답에 남은 복구 코드 수(`recoveryCodesLeft`)를 실어, 앱이 "남은 코드 2개 — 새로 만드세요"를 알린다.
   - 복구 코드를 만들 때의 비밀번호 확인 실패도 로그인 제한으로 센다(훔친 토큰으로 비밀번호를 맞혀 보지 못하게).
2. **아이디 찾기 (앱)** — 로그인 화면 「아이디를 잊었나요?」 → 도움 화면: ① 복구 코드로 찾기(코드만 넣으면 아이디를 알려 주고
   새 비밀번호까지), ② 같은 저장소 멤버에게 멤버 목록의 아이디를 물어보기, ③ 서버 운영자에게(PC 앱 「이 PC 에서 서버 열기」에서
   찾아 줄 수 있음).
3. **운영자 쪽 아이디 찾기 (서버 CLI)** — `npm run reset-password -- --find <이름 일부>` 로 이름·아이디로 계정을 찾는다. DB 를 가진
   운영자에게만 열린 도구라 새 권한이 생기지 않는다. (PC 앱 화면에 넣는 것은 IPC 4곳을 바꿔야 하고 여기서 `test:desktop` 을 못 돌려 뒤로.)
4. **연결 문제 해결 화면 (앱)** — `checkServer` 가 이유를 나눠 돌려준다: 응답 없음(시간 초과)·연결 거부/주소 없음(네트워크 오류)·
   ListUp 이 아닌 응답(HTTP 오류·JSON 아님, 터널이 끝났을 때 흔함)·버전 다름. `/troubleshoot` 화면이 지금 서버를 다시 확인하고
   이유별로 확인할 것을 차례로 보인다(서버 켜짐, 주소, 터널 주소 바뀜, https/http, 버전 업데이트). 서버 목록의 「닿지 않음」 배지와
   연결 오류 ErrorNotice 에서 들어온다.
5. **로그인이 끊긴 이유 알리기 (앱)** — 401 로 세션이 끝나면 로그인 화면에 "로그인이 끊겼습니다 — 비밀번호가 바뀌었거나 다른 기기에서
   모두 로그아웃했을 수 있습니다" 안내.
6. **로그인 실패 뒤 다음 할 일 (앱)** — 401 이면 「비밀번호를 잊었나요?」·「아이디를 잊었나요?」를 오류 아래에 바로, 429 면 남은 시간.

**하지 않는 것(지금은):** 기기(세션) 목록 — 토큰이 무상태(HMAC)라 기기마다 이름·마지막 사용을 보이려면 세션 표를 두고 요청마다
써야 한다(쓰기 부하·설계 변경). 지금은 「다른 기기 모두 로그아웃」으로 충분하다고 보고 TODO P3 에 적는다. 이메일 재설정은 P3 그대로.

### A. 처음 쓰는 사람 (앱만)

1. **도움말 화면 `/help`** — "ListUp 은 이렇게 씁니다": 서버(누가 돌리나)·계정(서버마다 따로)·저장소·역할(소유자/편집자/열람자)·
   변경 제안·초대 코드, 처음 시작하는 순서, 자주 생기는 문제(비밀번호·아이디·연결)로 가는 링크. 로그인·가입·저장소 목록·내 정보에서 연다.
2. **빈 화면에 할 일 버튼** — `EmptyState` 에 `action` 을 받게 해, 저장소가 없으면 「초대 코드로 참여」·「새 저장소 만들기」, 파일이 없으면
   편집자에게 「파일 올리기」, 열람자에게 「변경 제안 만들기」.
3. **가입 직후 복구 코드 권유** — 가입하면 저장소 목록 위에 "비밀번호를 잊을 때를 대비해 복구 코드를 만들어 두세요" 카드(닫을 수 있음).
4. 연결 오류 문장에서 「연결 문제 해결」로 바로(C4).

### B. 익숙한 사람 (앱만)

1. **파일 정렬** — 이름·크기·최근 수정, 오름/내림. 폴더는 늘 위. 기기에 기억. 순수 로직은 `app/src/lib/pure/` + 단위 테스트.
2. **키보드 단축키 (웹·PC 앱)** — `/` 파일 찾기 칸, `Backspace`·`Alt+↑` 위 폴더, `Esc` 검색 지우기·메뉴 닫기, `?` 단축키 목록.
   입력 칸에 글을 쓰는 중에는 반응하지 않는다.
3. **경로 복사·폴더 주소** — 행 ⋯ 메뉴에 「경로 복사」. 보고 있는 폴더를 주소의 `?path=` 에 남겨 새로고침·북마크·공유가 되게.
4. **여러 개 골라 한꺼번에** — 「고르기」로 체크 → 고른 것 삭제(한 번의 커밋)·받기. 이동은 서버에 여러 경로 이동이 없어 뒤로.
5. 고급 설정 접기 — 내 정보의 「다른 기기 로그아웃」·「복구 코드」·「저장된 로그인 지우기」를 「계정 보안」 묶음으로.
